# StormyOps

StormyOps is Ashlee Herken’s portfolio and application frontend built with Next.js and Tailwind CSS. It is being structured to support both a public-facing marketing/portfolio experience and an internal admin/CMS interface.

## Purpose

This project showcases:
- implementation and onboarding thinking
- full-stack system design
- frontend UI/UX work
- blog and content publishing workflows
- technical case studies and portfolio projects

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Project Structure

This frontend is being organized into two primary surfaces:
- public marketing/portfolio pages
- admin/CMS pages

The backend API lives in a separate repo.
